```bash

gh pr checks --watch
gh pr view --web
```

Replace template prompts with the actual summary, tests, evidence, limitations, and rollback notes. Review Files changed and confirm every required hosted check is green. Do not claim GitHub CI passed before it does.

After merging through GitHub using the normal repository policy:

```bash
cd /home/devansh/robotics_projects/ros2-amr-platform
git switch master
git pull --ff-only origin master
git log -1 --oneline --decorate
git status --short --branch
./scripts/build.sh

git diff --check

gh release create v0.1.3 --verify-tag --title "AMR Platform v0.1.3 — Readiness Contracts" --notes-file docs/v0.1.3_release_notes.md

Clone the public tag into an empty temporary directory and verify the README, links, evidence, license, package version, and tag/release association before social publication.
